# Telecomfort — инструкция пользователя

## 1. Установка и запуск

```bash
cargo build --release
./target/release/telecomfort
```

Приложение стартует в **демо-режиме** (мок-данные) — можно сразу смотреть все
экраны. Для live-режима нужны `api_id` / `api_hash` с https://my.telegram.org.

## 2. Вход в аккаунт (Настройки → 🔑 Telegram)

1. Создайте/выберите профиль, введите API ID, API HASH, телефон.
2. **По коду**: «Получить код» → код из Telegram → «Войти по коду».
   Если включён 2FA — введите пароль (подсказку покажет сервер) → «Войти с паролем».
3. **По QR**: «📷 Войти по QR» → отсканируйте код телефоном
   (Настройки Telegram → Устройства). «✕ Отменить QR» — остановка опроса.
4. **Прокси** (опционально): поле SOCKS5 `socks5://user:pass@host:port`,
   «🔌 Проверить прокси» — тест отдельным соединением.
5. Сессия хранится локально (`session_<профиль>.session`); «🚪 Выйти» стирает её.
   Экспорт/импорт сессии — кнопками в том же разделе.

## 3. Чаты (💬)

- Слева — диалоги (поиск 🌍, папки, ＋ группа/канал, 📍 рядом).
- Шапка чата: 📊 статистика · ℹ️ о чате (описание, числа, TTL, антиспам,
  тарифы подарков) · ⏳ автоудаление · 📅 прыжок к дате · 🎤 войс из файла ·
  ⭐ подарки · ⤵ экспорт · ⏰ отложенные · 📌 закрепы · 👥 участники.
- Композер: текст + Ctrl+Enter; 📎 складывает файлы в **очередь**
  (полоса над вводом, ✕ убирает) — отправятся с текстом как подпись
  (1 файл — файлом, несколько — альбомом). 🎙 — запись с микрофона
  (стоп ■ — отправка), 😀 — стикеры, 🎞 — GIF, ◉ — видео-кружок,
  📍 — геопозиция, 👤 — контакт, 🔕 — тихая отправка.
- На сообщениях: ↩ ответ, реакции (повтор — снять), 👥 кто реагировал,
  ✏️/🗑 правка своих, ⚠ жалоба на спам (чужие), 📌 закреп.
- ⏳ TTL: выкл / 1 день / 7 дней / 1 месяц / 1 год / своё (секунды).
- ⤵ Экспорт: JSON или HTML, опционально с медиа (до 150 файлов рядом).

## 4. Сторис (✨)

- Лента карточек с анти-рекламным скорингом; ＋ — публикация
  (фото/видео + подпись + 🎵 музыка mp3/m4a/ogg/wav/flac).
- Свои сторис: правка подписи, удаление (с подтверждением), архив.

## 5. Загрузки, контакты, сторис-статистика

- **⬇ Загрузки**: прогресс параллельных чанков, правила автозагрузки
  (per-chat: фото/видео/аудио/доки, лимит МБ), выгрузка в Yandex Disk,
  импорт книг в Calibre.
- **👥 Контакты**: добавить по телефону, чёрный список (блокировка/разблок).
- **⭐ Stars** (вход → баланс): 📜 — окно с историей транзакций
  (+вход/−расход, пиры, флаги) и моими подарками.

## 6. Настройки (⚙)

- **🎨/🔒**: тёмная/светлая тема (применяется сразу); PIN-блок
  (SHA-256, блокировка при старте + по кнопке + автоблок через N секунд
  бездействия); смена пароля 2FA (двойное подтверждение, новый пароль
  сразу проверяется).
- **📱 Сессии**: список, ⏏ завершить чужую, «Завершить другие».
- **✨ Сторис**: порог рекламы, blur, ONNX/CLIP-провайдер.
- **Профиль**: имя/фамилия/username/bio, фото, эмодзи-статус.

## 7. Устранение неполадок

| Симптом | Что делать |
|---|---|
| «connect: …» при входе | Проверить API ID/HASH, интернет, прокси (кнопка 🔌) |
| QR истёк | Запросить новый; сканировать вовремя (~время на экране) |
| Микрофон не пишется | Дать доступ в настройках ОС; статус покажет причину |
| Войс отправился как аудио | Так задумано: Opus-энкодер вне офлайн-сборки |
| Подарок не отправился | Нужны звёзды на балансе; sold out — в каталоге видно |
| Смена пароля не прошла | Неверный текущий пароль (см. Журнал); аккаунт не тронут |
| Всё сломалось | Журнал внизу + `RUST_LOG=telecomfort=debug` в консоли |
